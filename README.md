# Small-Stake Momentum Bot — Pump.fun Replay Sprint

A small-stake momentum trading bot for the [Pump.fun Replay Sprint](https://make.fun/bounty/u-jackxyz72-pump-fun-replay-sprint-paper-bot-0b809122): it trades 10 SOL of paper money on a 24h replay of recorded pump.fun bonding-curve activity, buying 0.02 SOL per curve only on tight momentum (rising price, broad-based net inflow, healthy curve) and exiting on an 8% stop loss, a 40% trailing stop, or a 5x take-profit.

Run with Node 22: `node main.ts` (the grader runs `node /bot/main.ts`).
